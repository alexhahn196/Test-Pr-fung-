## 3. Content-Arbitrage: abstrahierte Formate und eigene DE-Ansätze (Teil 25)

Je Format: was das internationale Vorbild abstrakt ausmacht, dann der eigene Ansatz. Die Winner-Merkmale aus [`09_winner_vs_loser.md`](09_winner_vs_loser.md) sind eingearbeitet: Konflikt-Hook ab 0:00, Regelbruch, feste Figur, emotionaler Payoff.

### 3.1 Senioren-Charakter kocht

| Element | Beobachtetes Prinzip (abstrahiert) | Eigener Ansatz |
|---|---|---|
| Hook-Prinzip | Alters-Schock bzw. Verbots-/Geheimnis-Satz | **Widerspruchs-Hook zur Küche:** „Mein Enkel sagt, Brot ohne Hefe geht nicht. Pass auf.“ / „Das Rezept hat mir meine Mutter 1952 verboten.“ Keine Gesundheits- oder Heilversprechen |
| Story-Struktur | Figur → Tipp/Rezept → Keyword-CTA | Konflikt-Satz → 3 Handgriffe (Zeitraffer) → Anschnitt/Reveal → ein Satz Lebensweisheit (Payoff) → „Kommentiere REZEPT“ |
| Länge | UNKNOWN (IG nicht gesehen); Cozy-Cooking 100–150 s | **30–45 s** Reel; Langfassung als YT-Short-Serie testen |
| Rhythmus | Figur spricht, Schnitt auf Hände/Topf | 1 Einstellung pro Handgriff, 0,5–0,7 Schnitte/s, Loop vom Anschnitt zum ersten Frame |
| Visuelle Mechanik | ältere Figur in warmer Küche | **eigene, wiederkehrende Figur** (z. B. „Oma Hedi, 84, Eifel“) mit fester Küche; **Kochgeschirr als Hauptrequisite im Bild** (Gusseisen, Emaille-Bräter) |
| Trigger | Überraschung, Identifikation, Wissen | Nostalgie + Identifikation + Wissen; Kaufnähe über sichtbares Werkzeug |

### 3.2 Cozy-Cooking

| Element | Beobachtetes Prinzip | Eigener Ansatz |
|---|---|---|
| Hook | Stimmung statt Konflikt (Wetter, Familie) | Stimmungs-Frame **plus** gesprochener Satz mit Einsatz („Nur einmal im Jahr, am ersten Frosttag…“), weil Stimmung allein laut R1 gerade sättigt (Feels Like HOME: 0 Millionen-Shorts in 30 T) |
| Struktur | Alltag → Kochen → Familienwärme | Anlass → Zubereitung → Tisch mit Familie → Rezeptkarte |
| Länge / Rhythmus | 100–150 s, ruhig, ohne Sprache | 45–60 s für Reels, ruhig, ASMR-Ton |
| Mechanik | Ghibli-/Anime-Stil, warmes Licht | eigener Illustrationsstil (kein Ghibli-Stil, Markennähe vermeiden), **deutsche Gerichte** (Sonntagsbraten, Kartoffelsalat, Plätzchen) |
| Trigger | Nostalgie, Wholesome | Nostalgie, Saison (Q4-Backen) |

### 3.3 Bau-/Transformation-Timelapse

| Element | Beobachtetes Prinzip | Eigener Ansatz |
|---|---|---|
| Hook | maximaler Materialsprung im ersten Frame (Alltagsobjekt → Luxus) | **DE-typischer Ausgangszustand** mit Kontrast: verfallene Schrebergartenlaube, Fachwerk-Ruine, alter Wasserturm |
| Struktur | Rohzustand → Zeitraffer → Reveal | Rohzustand → 5–7 Bauschritte mit sichtbarem **realem Werkzeug** → Reveal → „Werkzeugliste: Kommentiere LISTE“ |
| Länge / Rhythmus | 45–65 s, Zeitraffer, ASMR | 35–50 s, Schnitt je Bauschritt |
| Mechanik | KI-Bauprozess, unrealistische Bauzeit | Kennzeichnung „KI-Konzept“ im ersten Frame (wie Bau Rausch), **keine** Bauzeit- oder Kit-Versprechen |
| Trigger | Transformation, Status | Transformation + Heimat-Identifikation |

### 3.4 Zeitreise-Vlog

| Element | Beobachtetes Prinzip | Eigener Ansatz |
|---|---|---|
| Hook | Reporterin „vor Ort“ in historischer Situation, Warnung/Schock | eigene Figur, **deutsche Städte und Epochen** („Köln 1248: Die bauen hier seit 600 Jahren an einem Dom“) |
| Struktur | Ankunft → 3 Beobachtungen → Pointe | Ankunft → 3 Alltagsdetails (Essen, Geld, Hygiene) → Pointe → Buchtipp in der Caption |
| Länge / Rhythmus | 30–60 s | 30–45 s |
| Mechanik | Handkamera-POV, Selfie-Perspektive | gleiche Perspektive ist Gattungsmerkmal; Figur, Stimme und Städte eigen |
| Trigger | Überraschung, Wissen | Überraschung, Wissen, Lokalstolz |
| Risiken | – | keine NS-/Holocaust-Rekonstruktionen (Reputations- und Plattformrisiko, vgl. @zeitlabofc) |

## 4. Wo sich eine deutsche Adaption **nicht** lohnt

- **Story-Serien, Kids/Game, Fußball, Film-What-if:** Reichweite ist international und sprachfrei, Affiliate strukturell LOW, dazu Rechtsrisiken (reale Spieler, Franchise-IP, Minderjährige).
- **Satisfying/ASMR:** sprachneutral, also kein DE-Vorteil; Genre gesättigt.
- **Fruit-Soap, Baby-Podcast, Glass-Fruit:** Hype-Kurven sind schon abgeflacht (M1: tote Copycats).
