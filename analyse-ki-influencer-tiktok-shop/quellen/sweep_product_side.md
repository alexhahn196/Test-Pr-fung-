# Product-side sweep: TikTok Shop products/brands promoted with AI-generated affiliate videos -> accounts

Access date for everything below: 2026-09-24. Tags: **Verified** = seen in TikTok public data (tt_profile.sh / tt_video.sh) or a primary document (court filing); **Claimed** = asserted by a third party (article, YouTuber, Reddit poster, vendor site); **Estimated** = my own calculation (formula shown).

## Method and constraints (important for the reader)
- WebSearch budget of this session was exhausted before this sweep started (200/200). Bing/DuckDuckGo/Brave/Startpage/Yandex/Mojeek via curl or WebFetch were unusable (bot challenges or Bing returning unrelated results for every query). So this sweep relies on: (a) primary documents already cached in `research/` (404 Media article, TikTok Shop AIGC policy page, Reddit JSON dumps, YouTube transcripts), (b) a US federal court complaint downloaded from CourtListener, (c) WebFetch of specific brand/vendor pages, (d) NexLev YouTube search/transcripts, (e) `tt_profile.sh` / `tt_video.sh` for verification.
- Kalodata: every page (kalodata.com/blog, /knowledge, /product) is behind Cloudflare -> HTTP 403 for both curl and WebFetch. Nothing visible logged-out. **Not publicly verifiable.**
- FastMoss: blog is public (see UK top-creator list below); the product ranking page (`/e-commerce/saleslist`) renders column headers only ("Rank, Products, Country/region, Shop, Categories, Commission Rate, Units Sold, Order Growth Rate, GMV") and "No data" when logged out. **Not publicly verifiable.**
- EchoTik: blog and /products pages show only navigation when logged out. **Not publicly verifiable.**
- TikTok does not expose an account's video list headlessly, so per-video AI-label checks were only possible where a video URL was quoted somewhere (Pine Commerce, _keepher1, theamberjai).
